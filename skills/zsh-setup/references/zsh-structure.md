# zsh startup files on macOS — structure and templates (verified 2026-08-17)

## Load order and the path_helper quirk

Zsh reads, in order: `/etc/zshenv` → `~/.zshenv` → (login) `/etc/zprofile` →
`~/.zprofile` → (interactive) `/etc/zshrc` → `~/.zshrc` → (login)
`~/.zlogin`. macOS terminal tabs are **login + interactive** shells, so both
`.zprofile` and `.zshrc` run for every new tab.

macOS's `/etc/zprofile` runs `/usr/libexec/path_helper`, which **rebuilds
PATH** from `/etc/paths` + `/etc/paths.d` and then appends whatever was
already there. Consequence: PATH set in `~/.zshenv` gets reordered behind
system paths in every login shell. **Set PATH in `~/.zprofile` (after
/etc/zprofile has run) or `~/.zshrc` — never `~/.zshenv`.**

## What goes where

| File | Contents |
|---|---|
| `~/.zprofile` | login environment: `eval "$(/opt/homebrew/bin/brew shellenv)"` (owned by homebrew-setup), personal PATH prepends, `typeset -U path` (dedupes), `EDITOR`/`VISUAL` |
| `~/.zshrc` | interactive-only: framework/plugins, history, completion, tool init hooks, prompt, aliases |
| `~/.zshenv` | leave alone (or only non-PATH env needed by scripts) |

## Annotated ~/.zprofile template

```zsh
# Homebrew (Apple Silicon path; /usr/local on Intel)
eval "$(/opt/homebrew/bin/brew shellenv)"

# Personal executables first
path=("$HOME/.local/bin" $path)
typeset -U path PATH          # keep first occurrence, drop duplicates

export EDITOR="code --wait"   # or nvim
export VISUAL="$EDITOR"
```

## Annotated ~/.zshrc template — legacy (existing Oh My Zsh + Powerlevel10k setups)

The maintained default is the Starship template below. This one is for
machines that already run OMZ + p10k (both keep working; p10k is
maintenance-only) or users who explicitly ask for them.

```zsh
# p10k instant prompt (keep at very top; nothing may print above it)
if [[ -r "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh" ]]; then
  source "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh"
fi

export ZSH="$HOME/.oh-my-zsh"
ZSH_THEME="powerlevel10k/powerlevel10k"
plugins=(git per-directory-history zsh-autosuggestions zsh-syntax-highlighting)  # syntax-highlighting LAST
source "$ZSH/oh-my-zsh.sh"

# History
HISTSIZE=50000; SAVEHIST=50000
setopt SHARE_HISTORY HIST_IGNORE_ALL_DUPS HIST_IGNORE_SPACE

# Tool inits appended by other skills land here (fzf, zoxide, mise, direnv)

# Aliases
alias ll='ls -lah'

# p10k config (generated by `p10k configure`)
[[ -f ~/.p10k.zsh ]] && source ~/.p10k.zsh
```

## Annotated ~/.zshrc template — default (plain zsh + Starship)

```zsh
# History
HISTSIZE=50000; SAVEHIST=50000
setopt SHARE_HISTORY HIST_IGNORE_ALL_DUPS HIST_IGNORE_SPACE INTERACTIVE_COMMENTS AUTO_CD

# Completions
autoload -Uz compinit && compinit

# Plugins via Homebrew (syntax-highlighting LAST of the two).
# $HOMEBREW_PREFIX is exported by brew shellenv in .zprofile - using it
# avoids running `brew --prefix` (a real subprocess) on every startup.
source "$HOMEBREW_PREFIX/share/zsh-autosuggestions/zsh-autosuggestions.zsh"
source "$HOMEBREW_PREFIX/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh"

# Tool inits appended by other skills (fzf --zsh, zoxide, mise, direnv)

# Prompt - keep LAST
eval "$(starship init zsh)"
```

## Project facts (verified against upstream READMEs/repos)

- **Oh My Zsh installer** env/flags: `--unattended` (= `RUNZSH=no CHSH=no`),
  `--keep-zshrc` (`KEEP_ZSHRC=yes`); update with `omz update` (scripted:
  `zsh "$ZSH/tools/upgrade.sh"`). `per-directory-history` is bundled;
  toggle key Ctrl-G; global history file `~/.directory_history`.
- **zsh-autosuggestions / zsh-syntax-highlighting**: OMZ-custom clone or
  `brew install`; brew source paths are
  `$(brew --prefix)/share/zsh-autosuggestions/zsh-autosuggestions.zsh` and
  `$(brew --prefix)/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh`.
  Upstream: "zsh-syntax-highlighting must be the last plugin sourced".
- **Powerlevel10k status** (Aug 2026): README banner "VERY LIMITED SUPPORT /
  NO NEW FEATURES / MOST BUGS WILL GO UNFIXED"; repo not archived and still
  receives occasional commits; author (romkatv, May 2024): "powerlevel10k
  does not need ongoing active maintenance just to keep working."
  Brew formula exists (`brew install powerlevel10k`, source line
  `source $(brew --prefix)/share/powerlevel10k/powerlevel10k.zsh-theme`).
  Recommended font: its own MesloLGS NF TTFs (auto-installed by
  `p10k configure` on Terminal/iTerm2) or `font-meslo-lg-nerd-font` cask.
- **Starship**: `brew install starship`; init line at END of `.zshrc`;
  needs a Nerd Font; presets via `starship preset <name> -o
  ~/.config/starship.toml` (`no-nerd-font` preset exists for plain fonts).
- **Fonts**: the old `homebrew/cask-fonts` tap is dead — install font casks
  directly (`brew install --cask font-meslo-lg-nerd-font`).
- **fzf/zoxide init lines** (owned by dev-cli-tools): `source <(fzf --zsh)`
  (fzf ≥ 0.48); `eval "$(zoxide init zsh)"` **after compinit**.
- Default shell: zsh since macOS Catalina; `echo $SHELL` to confirm;
  `chsh -s /bin/zsh` only for old upgraded accounts.

## Startup profiling

```zsh
# temporarily: first line of .zshrc
zmodload zsh/zprof
# ... last line
zprof
```

Open a new shell, read the self-time table, remove both lines. Structural
fixes beat micro-optimizations: drop unused OMZ plugins, lazy-load version
managers, ensure compinit runs once, never run package managers in the
prompt hook.
